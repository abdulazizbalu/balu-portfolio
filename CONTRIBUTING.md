# Contributing

Thanks for checking out this project. This repository is part of a public portfolio, so changes should keep the project clear, reliable, and easy to review.

## Workflow

1. Open or reference an issue.
2. Create a focused branch.
3. Keep changes small and testable.
4. Run the project checks before opening a pull request.

## Quality Bar

- Keep UI consistent with the portfolio theme.
- Prefer simple, readable code.
- Update README/docs when behavior changes.
- Include screenshots or notes for visible changes.
