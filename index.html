How a project runs

  1. discover

    One call, then a short written brief: who uses it, what done looks like, what can break.

  2. spec

    A protocol before code: data, rules, acceptance criteria and test cases agreed up front.

  3. build

    I direct AI coding agents and review every diff. Fast iterations, small PRs, nothing unreviewed.

  4. verify

    Tests, evals and a reference to compare against. Results are reproducible.

  5. ship

    Deploy on Vercel or Railway, add monitoring, hand over docs and a runbook.
