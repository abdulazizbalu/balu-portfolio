Telegram Web A Lab

Working inside a large production codebase someone else owns is a different skill from greenfield work. These features follow the client's architecture, state management and design language, one branch and one pull request each.

7upstream PRs

Features

  • Remind Me: set a reminder on any message.
  • Share as Card: render a text message as a shareable image card with themes, sender header and chat footer; copy, save as PNG or send to any chat.
  • Chat Insights: a story-style summary computed on the client: totals, who talks more, busiest hours, top emoji, longest streak, most reacted message.
  • Storage Usage: how much the media cache takes, split by type, with per-type clearing and a donut chart.
  • Catch Up: a structured summary of unread messages: mentions, replies, questions, pinned messages and links, each jumping to the message.
  • Chat Calendar: a heat tint by message count and media thumbnails in the jump-to-date calendar.
