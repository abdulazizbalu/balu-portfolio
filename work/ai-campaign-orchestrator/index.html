AI Campaign Orchestrator: multi-channel campaign planning

Creators and small businesses usually have a good offer and scattered execution. The orchestrator turns one goal into one coherent campaign, then adapts the message per channel.

4channels
3provider modes
2export formats
v1.2.0release

Features

  • interactive campaign brief
  • local campaign library
  • mock / OpenAI / Anthropic provider mode
  • tasks for YouTube, short-form, email and Telegram
  • AI-ready prompt pack
  • Markdown and JSON export
  • risk register and review gates

Product decision

Business logic lives in a testable orchestrator module and the UI is separate, so the engine can become a real API or SaaS feature without a rewrite.
